# Midnight Ledger: phone playtest

The puzzles are proven solvable and every page's idea is machine-checked. **Whether they are fun, fair and hard for an interesting reason is untested.** The difficulty labels (1–5) are my estimates.

**Don't open `docs/EXPERT_SOLUTIONS_SPOILERS.md` before playing.**

## Install (keeps progress)
Install `build/tinystreet-v4-expert-debug.apk` **over** the current version (don't uninstall). It has the same package and debug key and versionCode 4. Your V3 save loads as is (no migration needed).

## Getting in
You need to have cleared campaign level 9 ("Ring the bell"). Then either tap **"Try expert mode"** on Home, or go to Challenges → **The Midnight Ledger**.

## 15–25 minute session
| Step | Do | Notice |
|---|---|---|
| 1 | Open the ledger and read the notice. Open **One Bell**. Tap the book icon for the rule card. | Are the rules clear before you move? |
| 2 | Play One Bell without hints. Then try ringing a second time. | Is the budget visible (strip, crossed-out bell, message)? |
| 3 | **The Last Shall Be First**: try to feed Mr. Basil early. | Is the "Not yet…" message clear? Did the order strip help? |
| 4 | **The Precise Hand**: aim for the precision badge (9 moves). | Is the move count clear? Does "proven minimum" mean anything to you? |
| 5 | Pick any two puzzles. Get properly stuck in one, then use hint 1, then 2, then 3. | Did each stage teach you something, or just give answers? |
| 6 | Make a mistake, open hint 3, and use "Undo to a solvable point". Try Redo too. | Was recovery smooth or frustrating? |
| 7 | Leave mid-puzzle (pause → The Midnight Ledger), reopen it. | Was your attempt restored? |
| 8 | After solving, read **Why this works**. | Did it match your reasoning? |
